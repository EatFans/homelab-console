# HomeLab Panel 视觉主题

## 方向：安静的家庭控制台

主题以**中性界面、单一品牌蓝、明确状态色**为核心。应用页的图标使用同一套颜色和容器，不再为每个功能赋予装饰性色彩。页面内容保持实体表面；底部常用应用栏使用轻微模糊和悬浮层次。默认跟随系统外观，浅色和深色是同等支持的两个版本。

这套主题是 HomeLab 的设计方案，并不直接复制其他产品界面或引入整套组件库。

## 参考与取舍

| 来源 | 借鉴点 | 在 HomeLab 中的用法 |
| --- | --- | --- |
| [Flutter 官方 Material 3 示例](https://github.com/flutter/samples/tree/main/material_3_demo) | 同一套组件支持浅色、深色、字级和颜色角色 | 继续使用 Flutter 自带 Material 组件与 `ThemeData` |
| [腾讯 TDesign Flutter](https://github.com/Tencent/tdesign-flutter) | 将颜色、字体、圆角等作为可集中维护的主题值 | 在 `PanelPalette` 中定义语义色，不为单个页面散落硬编码颜色 |
| [微软 Fluent UI](https://github.com/microsoft/fluentui) 与 [Fluent 2 色彩指南](https://fluent2.microsoft.design/color) | 中性色建立层级，品牌色点出交互，警告/成功/错误色只表达状态 | 大面积采用中性色，蓝色用于可操作和选中项，状态色不用于装饰 |
| [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials) | 悬浮导航与内容层明确分离，材质效果克制使用 | 仅在底部常用栏使用模糊；内容图标和卡片保持不透明 |

## 色彩角色

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| Canvas | `#F5F7F9` | `#121920` | 页面背景 |
| Surface | `#FFFFFF` | `#1D2832` | 图标容器与内容面板 |
| Surface muted | `#EBF0F4` | `#293642` | 次级层次与选中底色 |
| Text | `#18232E` | `#EDF3F7` | 标题与主要内容 |
| Text muted | `#627180` | `#A9B8C4` | 辅助说明 |
| Border | `#DCE4EA` | `#3A4854` | 必要的分隔 |
| Accent | `#2868B7` | `#91C2FF` | 可点击入口、选中状态与主要操作 |
| Warning | `#985D12` | `#F1BF79` | 未连接等需要注意的状态 |

状态信息必须同时使用文字或图标。蓝色只表示品牌和操作，不表示“在线”；警告色不作为图标的随机配色。未来接入 Hub 后，成功、失败和离线需要各自稳定的语义色与文案。

## 字体、尺寸与层次

- 使用系统中文字体，先不引入额外字体包。页标题约 30–32sp，分组标题 18–20sp，入口标签与正文 15–16sp，辅助信息不低于 13sp。
- 采用 8dp 间距基准；平板页面边距 24–32dp，入口之间至少留 16dp。触控区域按目标平板实测，页面图标容器当前为 80dp，常用栏图标容器为 54dp，整块入口均可点击。
- 内容容器圆角约 20–26dp，底部常用栏为胶囊形。只有浮动栏和必要的升层元素使用柔和阴影，普通容器主要靠背景与间距区分。
- 动效应帮助用户确认切换或操作结果；避免持续运动、强发光和大面积渐变。

## 组件规则

1. **常用应用栏**：跟随浅色/深色主题变换；固定在底部，可拖入、交换位置和移出。模糊只用于这一层，保证图标和文字始终清楚。
2. **应用入口**：统一的中性图标容器、蓝色线性图标和明确的中文标签。入口全区域可点，按窗口宽度调整列数，左右滑动切页。
3. **状态提示**：未连接、连接中、失败等使用图标 + 文案；应用页只在标题同行放一个紧凑状态标签，不占用独立说明区。状态区域不得伪装成已连接或可控制。
4. **功能页**：沿用同一表面、字体和导航规则；占位页清楚标注功能未实现。

实际实现位于 [`app/lib/theme/panel_theme.dart`](../app/lib/theme/panel_theme.dart)，`MaterialApp` 使用 `ThemeMode.system`。在 Android 和 iOS 的浅色、深色模式下都应检查可读性、触控目标与常用栏的拖放区域。
